# ChromeKiller
Kills all instances of Chrome, checks every 5 minutes. Useful for servers left unattended that may accumulate chrome instances over time (Chrome has a memory leak and ends up with hundreds of chrome.exe).

See: https://x.com/pftq/status/2016092732394242403
