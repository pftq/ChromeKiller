# ChromeKiller
Kills all instances of Chrome, checks every 5 minutes. Useful for servers left unattended with scrapers that may accumulate chrome instances over time (Chrome has a memory leak and ends up with hundreds of chrome.exe).

See: https://x.com/pftq/status/2016092732394242403

EXE for those just looking for something quick to download and run:
https://github.com/pftq/ChromeKiller/releases/tag/20260127
